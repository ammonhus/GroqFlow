# GroqFlow Implementation Plan

> **For agentic workers:** This plan is executed by parallel Opus subagents orchestrated via Workflow. Each task = one agent, one directory, zero file overlap. Foundation files (shared types, AppState, Package.swift) are ALREADY ON DISK — read them first, code against them exactly. Spec: `docs/superpowers/specs/2026-07-16-groqflow-design.md` (read it before your module).

**Goal:** Native macOS menu-bar dictation app (Wispr Flow clone) — hold Right Option to dictate, Groq Whisper STT + Llama formatting, paste at cursor.

**Architecture:** Single SwiftPM package. Library target `GroqFlowKit` (all code) + thin executable `GroqFlow` + test target `GroqFlowKitTests`. AppKit shell, SwiftUI views, MainActor UI. Modules communicate via `AppState` (ObservableObject) and closures wired in `DictationController` (integration task).

**Tech Stack:** Swift 6.2 toolchain, language mode v5, zero external packages, system libsqlite3, XCTest.

## Global Constraints

- macOS 14+ deployment target. Swift language mode `.v5`.
- No external SwiftPM dependencies. SQLite via `import SQLite3`.
- No emojis anywhere in code or UI copy. Light comments only.
- All UI classes `@MainActor`. Never block the main thread — Groq calls are `async`.
- API key ONLY via `KeychainHelper` — never UserDefaults, never files, never logged.
- Every file in ONE module directory; do not create or edit files outside your task's directory.
- Foundation types are law: `Sources/GroqFlowKit/App/SharedTypes.swift`, `AppState.swift`. If you need a type changed, note it in your final report instead of editing it.
- Tests: pure logic gets XCTest coverage in `Tests/GroqFlowKitTests/<Module>Tests.swift` (one file per module, yours to create). AppKit/network glue: no tests required.
- Do NOT run `git commit`. Do not touch `.git`.
- `swift build` may fail on OTHER modules while agents work in parallel; only ensure YOUR files are self-consistent against the foundation contracts.

### Task A: Hotkey module

**Files:** Create `Sources/GroqFlowKit/Hotkey/HotkeyClassifier.swift`, `Hotkey/HotkeyManager.swift`, `Tests/GroqFlowKitTests/HotkeyTests.swift`

**Produces (integration relies on exactly):**
```swift
public enum HotkeyAction: Equatable {
    case beginPushToTalk, endPushToTalk, toggleHandsFree
    case beginCommand, endCommand, cancel
}
public struct HotkeyClassifier {          // pure logic, no AppKit
    public init(holdThreshold: TimeInterval = 0.25, doubleTapWindow: TimeInterval = 0.35)
    public mutating func keyDown(at t: TimeInterval) -> HotkeyAction?
    public mutating func keyUp(at t: TimeInterval) -> HotkeyAction?
    public mutating func timerFired(at t: TimeInterval) -> HotkeyAction?   // fired holdThreshold after keyDown
    public var pendingTimerDeadline: TimeInterval? { get }
}
@MainActor public final class HotkeyManager {
    public init(settings: SettingsStore)
    public var onAction: ((HotkeyAction) -> Void)?
    public func start() -> Bool           // install CGEventTap .listenOnly; false if denied
    public func stop()
}
```

**Behavior:** CGEventTap listen-only on `flagsChanged` + `keyDown`. Dictation key from `settings.hotkey` (`HotkeyChoice` in SharedTypes: rightOption keyCode 61, rightCommand 54, fn 63, f5 96). Command chord = dictation key + Control held. Esc keyDown while active -> `.cancel`. Classifier semantics: keyDown starts hold timer; timerFired before keyUp -> `.beginPushToTalk`; keyUp after begin -> `.endPushToTalk`; keyUp before threshold -> tap; two taps within doubleTapWindow -> `.toggleHandsFree`; single tap alone -> nothing. Health loop: Task repeating every 5 s re-enables/reinstalls disabled tap. Do NOT consume events.

**Tests (write first):** hold promotes; quick release no-op; double-tap toggles; tap-then-hold works; timer deadline exposed correctly; cancel path. Drive classifier with synthetic timestamps.

### Task C: Groq module

**Files:** Create `Sources/GroqFlowKit/Groq/GroqAPI.swift`, `Groq/FormattingPrompt.swift`, `Groq/FormattingService.swift`, `Tests/GroqFlowKitTests/GroqTests.swift`

**Produces:**
```swift
public struct GroqAPI: Sendable {
    public init(apiKey: String)
    public func transcribe(wav: Data, language: String?, prompt: String?) async throws -> String
    public func chat(system: String, user: String, model: String, temperature: Double, jsonMode: Bool) async throws -> String
    public func validateKey() async -> Bool               // cheap models list call
}
public enum GroqModels {
    public static let stt = "whisper-large-v3-turbo"
    public static let formatter = "llama-3.1-8b-instant"
}
public enum FormattingPrompt {
    public static func system(context: AppContext, preset: StylePreset, dictionary: [DictionaryEntry], smartFormatting: Bool) -> String
    public static func commandSystem() -> String
    public static func sttPrompt(dictionary: [DictionaryEntry], context: AppContext) -> String  // <= 224 tokens ~ 900 chars, starred words first
}
public struct FormattingService: Sendable {
    public init(api: GroqAPI)
    public func format(raw: String, context: AppContext, preset: StylePreset, dictionary: [DictionaryEntry], snippets: [Snippet], smartFormatting: Bool) async -> String
    public func command(selected: String?, instruction: String) async -> String?
}
```

**Behavior:** Multipart upload to `/openai/v1/audio/transcriptions` (fields: model, file as audio.wav, language if non-nil, prompt if non-nil, response_format=json, temperature=0). Chat to `/openai/v1/chat/completions`; jsonMode sets `response_format:{"type":"json_object"}`. 30 s timeout, one retry on 5xx/network. `format`: snippet check first (exact/near match of normalized utterance vs trigger -> return body verbatim, no LLM call); if !smartFormatting return raw with basic sentence-case; else LLM with system prompt implementing spec's full rule set (fillers, Backtrack triggers "actually/scratch that/wait/no/I mean", spoken punctuation incl. "new line/new paragraph", never auto em-dash, numbered lists, digits, email/URL joining, style presets adjust ONLY caps/punct/spacing, code category no auto-caps + identifier casing, dictionary spellings enforced). Parse `{"text": ...}`; malformed -> one retry -> return raw. `command`: nil on failure so caller can abort.

**Tests:** prompt builder — dictionary words present, starred first, 900-char truncation, code category flag lines, preset lines; snippet matcher (case/punct-insensitive); JSON extraction incl. fenced/malformed input.
